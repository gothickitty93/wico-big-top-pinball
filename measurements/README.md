# Measurements

Record technical dimensions and layout references:
- cabinet width, height, depth
- playfield dimensions
- apron and rail measurements
- post dimensions and spacing
- switch plate spacing
- lamp and mounting locations
- coil and solenoid mounting dimensions
- clearance requirements for safe operation

Helpful files in this folder:
- `cabinet-dimensions.md`
- `playfield-layout.md`
- `part-dimensions.md`
